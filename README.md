# developer in the AI Era

A personal blog. Pure Angular SSG (prerendered HTML), markdown-authored
posts, GitHub Pages hosting, giscus comments. Zero CSS or UI libraries.

## Stack

- **Angular 21** with `@angular/build:application` and `outputMode: "static"` — every route is prerendered to HTML at build time.
- **Markdown posts** in `src/content/posts/*.md` with YAML frontmatter (`title`, `date`, `description`).
- **Build pipeline:** `scripts/generate-posts.mjs` parses the markdown (gray-matter + marked) into a typed TS module that the app imports. The pipeline runs as a `prebuild` hook so `ng build` always sees fresh data.
- **Comments:** [giscus](https://giscus.app) — backed by GitHub Discussions on this same repo.
- **CI/CD:** GitHub Actions builds and deploys on every push to `main`.

## Authoring a post

1. Create `src/content/posts/<slug>.md`:
   ```markdown
   ---
   title: My post
   date: 2026-05-02
   description: One-line summary for the home page (optional).
   ---

   Body in **markdown**.
   ```
2. Commit and push to `main`. The GitHub Action runs `npm run build` and deploys.

The slug is the filename without `.md` and becomes the URL: `/posts/<slug>`.

## Local development

```bash
npm install
npm run generate-posts   # one-time, regenerates posts-data.generated.ts
npm start                # http://localhost:4200
```

To preview the actual prerendered output:

```bash
npm run build
npx http-server dist/ai-era-blog/browser
```

## First-time GitHub setup

This is a **user site**, so the repo MUST be named `tenenberg.github.io`.

1. Create a new public repo at `https://github.com/new` named exactly `tenenberg.github.io`.
2. Locally:
   ```bash
   git remote add origin git@github.com:tenenberg/tenenberg.github.io.git
   git push -u origin main
   ```
3. In the repo's **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Push any commit (or run the workflow manually) — the site goes live at https://tenenberg.github.io.

## Wiring up giscus

Comments stay disabled (showing a placeholder) until you fill in two IDs:

1. In the repo: **Settings → General → Features → Discussions** (check it).
2. Install the giscus GitHub app: https://github.com/apps/giscus — grant access to `tenenberg.github.io`.
3. Visit https://giscus.app, fill in the form. It generates a `<script>` tag.
4. Copy the four `data-*` values from the generated tag into `src/app/components/giscus/giscus.ts`:
   - `GISCUS_REPO_ID`
   - `GISCUS_CATEGORY_ID`
   - (`GISCUS_REPO` and `GISCUS_CATEGORY` are pre-filled.)
5. Commit and push. Comments will render on every post.

```
    app.config.ts / app.config.server.ts

      home/                             List of all posts
      post/                             Single post + giscus comments
    components/
      giscus/                           Giscus comments component
    posts/
      post.ts                           Post interface
      posts-data.generated.ts           Generated by scripts/generate-posts.mjs
  content/
    posts/                              Markdown source — edit these
  index.html / styles.css / main.ts / main.server.ts / server.ts
scripts/
  generate-posts.mjs                    Markdown → typed TS at build time
.github/workflows/
  deploy.yml                            Build + deploy on push to main
```
