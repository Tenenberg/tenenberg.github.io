This is the first post on **developer in the AI Era** — a blog about what
the craft of software looks like now that the tools have changed.

The plan is to write about three things:

1. **Workflows** — concrete patterns for working with AI agents day-to-day,
   not the hype-cycle takes.
2. **The shape of the work** — what stays the same when the boilerplate
   evaporates, and what is genuinely different.
3. **Things I tried** — small experiments, what worked, what didn't, and
   why.

The posts here are static HTML, prerendered at build time from the
markdown files in `src/content/posts/`. Push to `main`, GitHub Actions
runs the build, and the new post is live a minute later.

If you want to leave a comment, scroll down — the comment box is wired
up to a GitHub Discussion via [giscus](https://giscus.app), so you'll
need a GitHub account to post.
